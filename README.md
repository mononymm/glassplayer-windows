# Glass for Windows

A library app for your Plex collection that plays everything in **your own mpv** — same config, shaders, Glass controls and Plex sync — embedded in the window.

- Home: rotating backdrop hero with title logos, Continue watching with episode stills, recently added per library.
- Show pages: full-bleed art, season tabs, episode stills with summaries and progress. Movie pages with format info.
- Reads Plex's database and artwork folders directly (a private copy), so it works whether or not Plex is running.
- Watch progress: newest of Plex's record and mpv's `glass-positions.json`.

Keys: Ctrl+F search · Esc / Backspace / mouse back button to go back · F5 refresh.

Download `Glass.exe` from the **latest** release. Settings are in `%APPDATA%\Glass\settings.json` (mpv and Plex folders are found automatically).
